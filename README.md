# 运费统计系统 (Freight Statistics System)

这是一个基于 PHP + MySQL 的轻量级运费录入与统计系统。支持移动端扫码录入、运费自动统计、以及后台报表查看功能。专为移动设备优化，界面简洁高效。

## ✨ 主要功能

*   **扫码录入**：
    *   集成 `html5-qrcode`，支持手机摄像头直接扫描快递单号。
    *   自动识别物流商（支持韵达、信丰、顺丰等规则）。
    *   实时显示最近录入的 3 条记录，防止重复或遗漏。
*   **后台统计**：
    *   采用 **AdminLTE 3** 风格的响应式管理界面。
    *   支持按日期范围、运单号筛选查询。
    *   提供总单量和总运费的实时统计。
    *   移动端适配优化：自动隐藏非核心元素，支持弹窗查看详情。
*   **安全管理**：
    *   系统初始化安装向导。
    *   管理员登录认证（Session + 数据库哈希存储）。
    *   支持修改管理员密码。
*   **数据导入**：
    *   支持 CSV 文件批量导入历史数据。

## 🛠️ 技术栈

*   **后端**：PHP (原生, 无框架依赖)
*   **数据库**：MySQL
*   **前端**：HTML5, Bootstrap 4, AdminLTE 3, jQuery
*   **扫码库**：html5-qrcode

## 🚀 安装与部署

1.  **环境要求**：
    *   PHP 7.0+
    *   MySQL 5.6+
    *   Web 服务器 (Apache/Nginx/IIS)

2.  **安装步骤**：
    *   将项目文件上传至服务器目录。
    *   在浏览器中访问 `init.php`（例如：`http://your-domain/init.php`）。
    *   填写数据库连接信息（主机、用户名、密码、数据库名）。
    *   设置系统管理员密码。
    *   点击“开始安装”，系统将自动创建配置文件和数据库表。

3.  **安全建议**：
    *   安装完成后，建议删除 `init.php` 文件以防止被恶意重置。

## 📖 使用指南

### 1. 运费录入 (`index.html`)
*   访问首页，输入管理员密码登录。
*   点击“允许使用摄像头”权限。
*   对准快递单条形码即可自动扫描填入单号。
*   输入运费金额，点击“上传”或直接扫描下一个。

### 2. 后台报表 (`report.html`)
*   点击录入页底部的“进入后台统计”链接。
*   在后台可以查看所有录入记录。
*   **移动端体验**：在手机上查看时，点击表格行可弹出详情卡片，表格只显示关键信息，界面更加清爽。
*   **修改密码**：点击右上角菜单可修改登录密码。

## 📂 文件结构说明

*   `index.html` - 扫码录入主页
*   `report.html` - 后台统计报表页面
*   `init.php` - 系统安装程序
*   `fee.php` - 接收录入数据的后端接口
*   `api_stats.php` - 提供统计数据的 API 接口
*   `login_api.php` - 处理登录请求
*   `change_password_api.php` - 处理密码修改
*   `check_install.php` - 检测安装状态的辅助脚本
*   `db_schema.sql` - 数据库建表语句
*   `html5-qrcode.min.js` - 扫码功能库
*   `ok.mp3` / `err.mp3` - 扫描操作音效
